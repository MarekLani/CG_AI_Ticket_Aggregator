# UI standard

The initial product is an operational internal tool; optimize for clarity and scanability over decorative UI.

Mandatory states for data views:
- loading;
- empty;
- error;
- populated.

The primary list should make source, title, type, status, product, priority, assignee and relevant dates easy to scan when those fields exist.

Do not introduce a large custom component library in the bootstrap. Reuse existing project components once established.
