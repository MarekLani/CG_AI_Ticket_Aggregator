Čomu sa budeme venovať

Počas školenia budeme vyvíjať aplikáciu Unified Work Items, ktorá načíta pracovné položky z Helpdesku, Microsoft Planneru a GitHub Issues a zobrazí ich v jednom spoločnom pohľade na čítanie. Na tomto príklade si postupne prejdeme návrh aplikácie, vývoj s GitHubom a AI agentmi, kontajnery, Terraform, Azure hosting aj automatické buildy, testy a nasadenie.

Pokračovanie vo vývoji aplikácie

Po technických témach sa vrátime k Unified Work Items. Jednoduchý základ už máme lokálne aj v Azure a môžeme ho rozširovať o reálnu funkcionalitu podľa implementačných celkov z prezentácie 01.

Celok B · Helpdesk

  • model WorkItem;
  • konektor Helpdesku;
  • GET endpoint;
  • tabuľka s reálnymi dátami.

Celok C · Pracovný zoznam

  • vyhľadávanie a filtre;
  • načítavanie, prázdny výsledok a chyby;
  • odkaz do zdrojového systému;
  • základná kontrola použiteľnosti.

Ďalej podľa času

  • Entra ID;
  • monitorovanie aplikácie;
  • Planner konektor;
  • GitHub Issues konektor.
