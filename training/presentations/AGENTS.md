# Agent Instructions — Training Presentations

## Scope

Applies only to `training/presentations/`.

## Access rule

Do not read or use files in this folder unless the current issue/task explicitly asks you to work on the training presentations or related training material.

## When presentation work is explicitly requested

- Treat these decks as teaching material, not as a canonical source of product, architecture, or engineering requirements.
- Verify project-specific statements against the relevant canonical files under `docs/`, ADRs, standards, and the current approved GitHub issue/plan before changing presentation content.
- If presentation content conflicts with canonical project documentation, the canonical project documentation wins; update the presentation rather than inferring a project change.
- Keep presentation-only changes inside this folder unless the approved scope explicitly requires changes elsewhere.
- Do not change application architecture, standards, infrastructure requirements, or implementation behavior merely to make them match a slide.
