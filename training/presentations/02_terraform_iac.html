Repo boundary

U nás je infraštruktúra samostatný repozitár

Application repo

Kód aplikácie, architektúra aplikácie, aplikačné štandardy, runtime požiadavky, budúce DB migrácie.

Infrastructure repo

Terraform, Azure resources, networking, identity/RBAC platformy, environment konfigurácia a deployment infraštruktúry.

Toto je zámerné architektonické rozhodnutie, nie náhodná organizácia súborov.
