Dôležitý framing

Docker znalosť neznamená, že každý workload musí byť nasadený ako Docker image.

V tomto projekte sú kontajnery najmä vývojový a testovací nástroj. Azure hosting vyberáme podľa potrieb aplikácie.

Rozhodnutie pre túto appku

Unified Work Items: Azure Functions Flex, nie Container Apps

Prečo Flex

  • malá interná aplikácia;
  • API workload;
  • serverless prevádzkový model;
  • bez potreby vlastného runtime image.

Prečo nie Container Apps

  • nepotrebujeme vlastný image;
  • nepotrebujeme Dapr/sidecars/revisions ako primárny dôvod;
  • nechceme zbytočnú image lifecycle zodpovednosť.

Rozhodovací rámec

Kód / funkcia

Nasadiť ako Azure Functions Flex, ak nepotrebujeme vlastný runtime image.

Container image
